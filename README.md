# GitHub Profile Finder


A **React web application** to search GitHub profiles, view detailed user information, and track recent searches using Github RestFull API. Fully responsive with a modern, animated UI.

---

## 🛠️ Technologies

- React
- GitHub REST API
- Material UI

## 💡 Features

- Search GitHub users by **username**.
- View profile details:  
- Track **recent searches** with timestamp (`x min ago`).
- Click history items to reload profiles instantly.
- Responsive design for mobile and desktop.
- Smooth gradient animations and visual feedback for loading/error states.
